# TaskBoard

Дошка завдань: навчальний наскрізний проєкт з дисципліни
«Технології створення веб-застосунків».

## Про проєкт

Зараз у проєкті є головна сторінка та сторінка про проєкт.
У майбутньому TaskBoard дозволятиме створювати завдання,
змінювати їхні статуси та відстежувати виконання.

## Як запустити

1. Склонуй репозиторій:

   ```powershell
   git clone https://github.com/Bohdan648/taskboard.git
   cd taskboard
   ```

2. Відкрий папку taskboard у VS Code.
3. Встанови розширення Live Server від Ritwick Dey.
4. Натисни правою кнопкою на index.html → Open with Live Server.
