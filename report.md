## 1. Яка адреса сторінки в браузері? З яких частин вона складається?

Адреса сторінки: http://127.0.0.1:5500/index.html. Тут http — протокол, 127.0.0.1 — адреса мого комп’ютера, 5500 — порт сервера, а /index.html — шлях до сторінки.

## 2. Скільки запитів зробив браузер і чому саме стільки?

Браузер зробив 3 запити: index.html, logo.png і ws. Перші два завантажують сторінку та картинку, а WebSocket потрібен Live Server для автоматичного оновлення.

## 3. Що відбулось за неправильного шляху до зображення?

Я змінив шлях на images/logo1.png і отримав помилку 404 Not Found. Картинка зникла, замість неї з’явився текст «Логотип TaskBoard», а в Network запит став червоним.

## 4. Чому зміни через DevTools зникають після F5?

DevTools змінює сторінку в пам’яті браузера, а файл index.html залишається без змін. Після F5 браузер завантажує сторінку із сервера заново, тому тимчасові зміни зникають.

## 5. Хто тут клієнт, а хто сервер?

Клієнт — браузер, який надсилає запити й показує сторінку. Сервер — Live Server на моєму комп’ютері, який повертає файли сторінки та зображення.

## Дослідження Network

| Запит | Метод | Статус | Тип | Розмір |
| --- | --- | --- | --- | --- |
| index.html | GET | 200 | document | 2.4 kB |
| logo.png | GET | 200 | png | 2.1 kB |
| ws | GET | 101 | websocket | 0.0 kB |

## Elements і Console

Зміна заголовка через Elements не змінює файл index.html. Після F5 повертається заголовок із файлу.

Команда `document.title` повертає "TaskBoard".

Команда `document.body.style.background = "lightyellow"` змінює фон на світло-жовтий. Після F5 початковий фон відновлюється, бо зміна не записана у файл.

## Додаткове завдання

Додав сторінку about.html і посилання «Про проєкт» та «На головну» для переходу між сторінками.

Для адреси http://127.0.0.1:5500/qwerty очікується помилка 404 Not Found, оскільки такої сторінки в проєкті немає.

У терміналі VS Code виконав команду:

```powershell
curl.exe -I http://127.0.0.1:5500/index.html
```

Отримав такі результати:

| Поле | Значення |
| --- | --- |
| Статус | 200 OK |
| Content-Type | text/html; charset=UTF-8 |
| Content-Length | 617 |

Статус і Content-Type збігаються з результатами у DevTools.

Команда з параметром -I використовує метод HEAD і повертає лише заголовки відповіді. Звичайне завантаження сторінки в браузері використовує GET та повертає також її вміст.
