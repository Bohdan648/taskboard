# Як виконати лабораторну №2

## 1. Відкрий проєкт

1. Розпакуй архів. Перенеси папку taskboard у C:\webdev\, щоб файл сторінки був за шляхом C:\webdev\taskboard\index.html.
2. У VS Code вибери File → Open Folder → C:\webdev\taskboard.
3. Натисни Ctrl+Shift+X. Знайди та встанови Live Server від Ritwick Dey.
4. Відкрий index.html і замість ____ вкажи свою групу. Збережи через Ctrl+S. Також впиши групу в report.md.

## 2. Запусти сторінку

1. Натисни правою кнопкою миші на index.html → Open with Live Server.
2. У браузері має відкритися адреса на зразок http://127.0.0.1:5500/index.html. Якщо порт інший, у звіті вкажи свій.
3. Перевір, що видно заголовок, картинку, текст, автора й посилання.
4. Зміни текст абзацу у VS Code та натисни Ctrl+S. Переконайся, що браузер оновився автоматично.

## 3. Перевір Network

1. У браузері натисни F12. Якщо не відкривається, спробуй Ctrl+Shift+I.
2. Вибери Network → All, увімкни Disable cache і вимкни Preserve log. Очисть список кнопкою Clear та натисни F5.
3. Перепиши у report.md назви запитів, Method, Status, Type і Size. Якщо стовпців не видно, натисни правою кнопкою на заголовках таблиці та увімкни потрібні.
4. Натисни на index.html → Headers. Запиши Request URL, Request Method, Status Code і Content-Type у Response Headers.
5. Порахуй усі запити зі свого списку, включно з додатковими, та впиши кількість у відповідь №2.

У report.md є очікувані значення та місця для твоїх результатів. Зістав приклади зі своїм Network: браузер може додати favicon.ico, а розміри й кількість запитів залежать від браузера та кешу.

## 4. Отримай і зафіксуй помилку 404

1. У index.html тимчасово зміни src="images/logo.png" на src="images/logo1.png".
2. Збережи файл, перейди в браузер і натисни F5.
3. У Network знайди logo1.png зі статусом 404. Картинка зникне, а замість неї буде текст з alt.
4. Натисни Win+Shift+S, виділи вкладку Network з помилкою та збережи скріншот у папку screenshots під назвою network_404.png. Якщо папки немає, створи її.
5. Обов'язково поверни src="images/logo.png" і збережи файл. Перевір, що картинка знову показується.
6. У report.md познач, що скріншот зроблено.

## 5. Перевір Elements

1. Відкрий вкладку Elements і знайди <h1>TaskBoard</h1>.
2. Двічі натисни на текст TaskBoard, зміни його на TaskBoard — моя дошка й натисни Enter.
3. Заголовок у браузері зміниться, але файл index.html у VS Code залишиться без змін.
4. Натисни F5. Браузер знову покаже заголовок із файлу.

## 6. Перевір Console

У Console виконай команди по черзі:

```javascript
document.title
document.body.style.background = "lightyellow"
```

Перша поверне "TaskBoard". Друга змінить фон сторінки на світло-жовтий. Після F5 фон знову стане білим, оскільки ці зміни не записані у файл.

## 7. Додаткове завдання

1. Відкрий посилання «Про проєкт», потім «На головну». Файл about.html уже додано.
2. Відкрий http://127.0.0.1:5500/qwerty. Live Server має повернути 404 Not Found, бо такого шляху немає.
3. Відкрий термінал у VS Code через Ctrl+` і виконай:

```powershell
curl.exe -I http://127.0.0.1:5500/index.html
```

Якщо Live Server працює на іншому порту, зміни 5500 у команді. Параметр -I надсилає запит HEAD: сервер повертає заголовки без вмісту сторінки. У DevTools звичайне завантаження сторінки використовує GET. Порівняй статус, Content-Type та інші заголовки й коротко запиши результат у report.md.

## Перед здачею

- Впиши групу в index.html та report.md.
- Звір таблицю Network і кількість запитів зі своїм браузером.
- Зроби власний скріншот помилки 404 та віднови правильний шлях до картинки.
- Покажи викладачу сторінку, запущену через Live Server, і report.md.
- Збережи папку taskboard для наступних лабораторних.
