# Лабораторна робота №2. Перша сторінка

## 1. Яка адреса сторінки в браузері? З яких частин вона складається?

Адреса сторінки: http://127.0.0.1:5500/index.html. Тут http — протокол, 127.0.0.1 — адреса мого комп’ютера, 5500 — порт сервера, а /index.html — шлях до сторінки.

## 2. Скільки запитів зробив браузер і чому саме стільки?

Браузер зробив 3 запити: index.html, logo.png і ws. Перші два завантажують сторінку та картинку, а WebSocket потрібен Live Server для автоматичного оновлення.

## 3. Що відбулось за неправильного шляху до зображення?

Я змінив шлях на images/logo1.png і отримав помилку 404 Not Found. Картинка зникла, замість неї з’явився текст «Логотип TaskBoard», а в Network запит став червоним.

## 4. Чому зміни через DevTools зникають після F5?

DevTools змінює сторінку в пам’яті браузера, а файл index.html залишається без змін. Після F5 браузер завантажує сторінку із сервера заново, тому тимчасові зміни зникають.

## 5. Хто тут клієнт, а хто сервер?

Клієнт — браузер, який надсилає запити й показує сторінку. Сервер — Live Server на моєму комп’ютері, який повертає файли сторінки та зображення.

## Помилка 404

За шляхом images/logo1.png сервер не знайшов зображення та повернув статус 404.

![Помилка 404 у Network](../screenshots/network_404.png)

## Elements і Console

Зміна заголовка через Elements не змінює файл index.html. Після F5 повертається заголовок із файлу.

Команда `document.title` повертає "TaskBoard".

Команда `document.body.style.background = "lightyellow"` змінює фон на світло-жовтий. Після F5 початковий фон відновлюється, бо зміна не записана у файл.

## Додаткове завдання

Додав сторінку about.html і посилання «Про проєкт» та «На головну» для переходу між сторінками.

Для адреси http://127.0.0.1:5500/qwerty очікується помилка 404 Not Found, оскільки такої сторінки в проєкті немає.

У терміналі VS Code виконав команду:

```powershell
curl.exe -I http://127.0.0.1:5500/index.html
```

Отримав такі результати:

| Поле | Значення |
| --- | --- |
| Статус | 200 OK |
| Content-Type | text/html; charset=UTF-8 |
| Content-Length | 617 |

Статус і Content-Type збігаються з результатами у DevTools.

Команда з параметром -I використовує метод HEAD і повертає лише заголовки відповіді. Звичайне завантаження сторінки в браузері використовує GET та повертає також її вміст.


# Лабораторна робота №4. Git у терміналі

## 1. Що змінилося у git status після git add?

Файл перейшов у розділ Changes to be committed і став зеленим. Це означає, що зміни підготовлені до коміту.

## 2. Що показує git diff?

git diff показує відмінності між робочими файлами та індексом. Рядки з «+» додані, а з «-» — видалені.

## 3. Чим відрізняється git switch main від git merge?

git switch main перемикає мене на гілку main. git merge об’єднує зміни вказаної гілки з поточною.

## 4. Чому виник конфлікт і як я його розв’язав?

Конфлікт виник, бо в main та ukr-title я по-різному змінив той самий рядок із заголовком. Я прибрав маркери конфлікту, залишив заголовок «Дошка завдань: керуй завданнями» та завершив злиття комітом.

## 5. Скільки комітів у моїй історії?

На завершення лабораторної №4 в історії було 8 комітів. Нижче наведено історію перед фінальним комітом зі звітом, коли їх було 7.

Вивід git log --oneline --graph перед фінальним комітом:

```text
|\
| * d350fc3 Перекласти заголовок українською
* | 4b3dadd Розширити заголовок
|/
* d366742 Додати сторінку про проєкт
* ec646a0 Додати опис проєкту на головну
* 26e47fd Додати логотип, звіт і .gitignore
* 2d1531e Додати головну сторінку
```


# Лабораторна робота W-07. Сторінка «Про автора»

Семантична розмітка — це використання тегів, які пояснюють призначення частин сторінки. На відміну від звичайного div, теги header, nav, main, section, article і footer відразу показують структуру вмісту. Така розмітка полегшує читання коду та допомагає пошуковим системам і програмам зчитування з екрана краще розуміти сторінку.

Використані теги:

- Структура документа: html, head, meta, title, body.
- Семантичні блоки: header, nav, main, section, article, footer.
- Заголовки й текст: h1, h2, p, strong, em, span, div.
- Зображення: figure, img, figcaption.
- Списки та посилання: ul, li, a.
- Таблиця: table, thead, tbody, tr, th, td.
